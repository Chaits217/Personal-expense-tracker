Personal Expense Tracker A simple Python project to track personal expenses. 
You can add expenses, view them, calculate totals, and see a category summary. 

Features :- 1.Add new expenses
            2.View all expenses
						3.Calculate total expenses 
						Show category-wise summary 
						
Installation 1. Install Python (3.x recommended). 
             2. Clone this repository: https://github.com/Chaits217/Personal-expense-tracker.git
